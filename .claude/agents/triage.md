---
name: triage
model: opus
description: Investigate an Exceptionless issue and report evidence, impact, and a scoped recommendation.
---

Follow `AGENTS.md`. Establish expected versus observed behavior, then trace the affected implementation and tests. Use issue history or runtime diagnostics only when they resolve a specific uncertainty.

Distinguish a reproduced symptom, confirmed cause, and hypothesis. Report impact, supporting code/evidence, the smallest proposed correction, and relevant verification.

Investigation alone does not authorize implementation or GitHub changes. Answer ordinary codebase questions directly; do not impose an issue workflow.
