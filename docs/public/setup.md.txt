# Set up Exceptionless

Instructions for a coding agent adding Exceptionless error and event tracking to an app.

## Before you start

- Use the API key the user gave you in place of `YOUR_API_KEY`. If they didn't give one, ask for it. It's on the project's API Keys page in Exceptionless.
- If the user gave you a server URL, they run their own Exceptionless server. Set the client's server URL to it (`c.ServerUrl` in .NET, `c.serverUrl` in JavaScript), and send REST API requests to it instead of `https://collector.exceptionless.io`. Otherwise keep the client's default server.
- If the project already keeps settings like this in configuration or environment variables, put the API key there.

## Steps

1. Work out the app's language and framework, and find the matching section below. For a platform that isn't listed, use REST API (curl).
2. Follow its steps, adapting file names and structure to this project.
3. Run the app once so the test error "Hello from Exceptionless setup" is sent. Confirm it was accepted, then remove the test code.
4. Tell the user what you changed. The test event appears in Exceptionless within a few seconds.

## ASP.NET Core

.NET. Docs: https://exceptionless.com/docs/clients/dotnet/

### 1. Install Exceptionless.AspNetCore

Run this from your project folder.

```bash
dotnet add package Exceptionless.AspNetCore
```

### 2. Add Exceptionless to Program.cs

Register the client and middleware in Program.cs. Settings in appsettings.json under "Exceptionless" work too.

```csharp
using Exceptionless;

var builder = WebApplication.CreateBuilder(args);
builder.AddExceptionless(c => {
    c.ApiKey = "YOUR_API_KEY";
});
builder.Services.AddProblemDetails();

var app = builder.Build();
app.UseExceptionHandler();
app.UseExceptionless();
```

### 3. Send a test error

Add this after app.UseExceptionless(), run your app once, then remove it.

```csharp
new Exception("Hello from Exceptionless setup").ToExceptionless().Submit();
```

### Optional: Send your logs

Send warnings and errors from ILogger too. You can tune log levels per source later from project settings.

```bash
dotnet add package Exceptionless.Extensions.Logging
```

```csharp
builder.Logging.AddExceptionless();
```

## Console app (.NET)

.NET. Docs: https://exceptionless.com/docs/clients/dotnet/

### 1. Install Exceptionless

Run this from your project folder.

```bash
dotnet add package Exceptionless
```

### 2. Start Exceptionless and send a test error

Start the client when your app starts. The second line sends a test error so you can see it arrive.

```csharp
using Exceptionless;

ExceptionlessClient.Default.Startup("YOUR_API_KEY");

new Exception("Hello from Exceptionless setup").ToExceptionless().Submit();

// Console apps exit quickly, so send anything queued before exiting.
await ExceptionlessClient.Default.ProcessQueueAsync();
```

## Worker Service (.NET)

.NET. Docs: https://exceptionless.com/docs/clients/dotnet/

### 1. Install Exceptionless.Extensions.Hosting

Run this from your project folder.

```bash
dotnet add package Exceptionless.Extensions.Hosting
```

### 2. Add Exceptionless to Program.cs

Register the client in Program.cs. It flushes queued events when the host stops.

```csharp
using Exceptionless;

var builder = Host.CreateApplicationBuilder(args);
builder.AddExceptionless(c => {
    c.ApiKey = "YOUR_API_KEY";
});
builder.Services.AddHostedService<Worker>();

var host = builder.Build();
host.Run();
```

### 3. Send a test error

Add this just before host.Run(), run your worker once, then remove it.

```csharp
host.Services.GetRequiredService<ExceptionlessClient>()
    .SubmitException(new Exception("Hello from Exceptionless setup"));
```

### Optional: Send your logs

Send warnings and errors from ILogger too.

```bash
dotnet add package Exceptionless.Extensions.Logging
```

```csharp
builder.Logging.AddExceptionless();
```

## Angular

JavaScript. Docs: https://exceptionless.com/docs/clients/javascript/

### 1. Install the client

Run this from your project folder.

```bash
npm install @exceptionless/browser
```

### 2. Start Exceptionless and add an ErrorHandler

Start the client in main.ts and route Angular’s errors to Exceptionless with an ErrorHandler.

```javascript
import { ErrorHandler, Injectable } from "@angular/core";
import { bootstrapApplication } from "@angular/platform-browser";
import { Exceptionless, toError } from "@exceptionless/browser";
import { AppComponent } from "./app/app.component";

Exceptionless.startup((c) => {
  c.apiKey = "YOUR_API_KEY";
});

@Injectable()
export class ExceptionlessErrorHandler implements ErrorHandler {
  handleError(error: unknown): void {
    console.error(error);
    Exceptionless.submitException(toError(error));
  }
}

bootstrapApplication(AppComponent, {
  providers: [{ provide: ErrorHandler, useClass: ExceptionlessErrorHandler }]
});
```

### 3. Send a test error

Run this once after startup, for example from a button click.

```javascript
Exceptionless.submitException(new Error("Hello from Exceptionless setup"));
```

## React Native

Mobile. Docs: https://github.com/exceptionless/Exceptionless.JavaScript/tree/main/packages/react-native

### 1. Install the client

AsyncStorage keeps queued events across restarts, so install it alongside the client.

```bash
npm install @exceptionless/react-native @react-native-async-storage/async-storage
cd ios && pod install
```

### 2. Start Exceptionless

Start the client once when your app mounts and wrap your app in the error boundary.

```javascript
import { useEffect } from "react";
import { Exceptionless, ExceptionlessErrorBoundary } from "@exceptionless/react-native";

export default function App() {
  useEffect(() => {
    Exceptionless.startup((c) => {
      c.apiKey = "YOUR_API_KEY";
    });
  }, []);

  return (
    <ExceptionlessErrorBoundary>
      <Root />
    </ExceptionlessErrorBoundary>
  );
}
```

### 3. Send a test error

Run this once after startup, for example from a button press.

```javascript
Exceptionless.submitException(new Error("Hello from Exceptionless setup"));
```

## REST API (curl)

Command line. Docs: https://exceptionless.com/docs/api/

### 1. Send a test error

Run this in your terminal. Any language that can make an HTTP request can send events the same way.

```bash
curl "https://collector.exceptionless.io/api/v2/events" \
  --request POST \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Content-Type: application/json" \
  --data-binary '{"type":"error","environment":"production","@simple_error":{"message":"Hello from Exceptionless setup","type":"System.Exception","stack_trace":"   at Setup.SendTestError()"}}'
```

## PowerShell

Command line. Docs: https://exceptionless.com/docs/api/

### 1. Send a test error

Run this in PowerShell to send one error event.

```powershell
$body = @{
  type = "error"
  environment = "production"
  "@simple_error" = @{
    message = "Hello from Exceptionless setup"
    type = "System.Exception"
    stack_trace = "   at Setup.SendTestError()"
  }
} | ConvertTo-Json -Depth 5

Invoke-RestMethod -Method Post -Uri "https://collector.exceptionless.io/api/v2/events" `
  -Headers @{ Authorization = "Bearer YOUR_API_KEY" } `
  -ContentType "application/json" -Body $body
```


### 2. Start Exceptionless and send a test error

```csharp
using Exceptionless;

ExceptionlessClient.Default.Startup("YOUR_API_KEY");
```

## ASP.NET MVC

.NET Framework. Docs: https://exceptionless.com/docs/clients/dotnet/

### 1. Install Exceptionless.Mvc

Run this in the Visual Studio Package Manager Console.

```powershell
Install-Package Exceptionless.Mvc
```

### 2. Add your API key to web.config

NuGet adds this to web.config for packages.config projects. Check it is there with your API key; PackageReference projects need it added by hand.

```xml
<configSections>
  <section name="exceptionless" type="Exceptionless.ExceptionlessSection, Exceptionless" />
</configSections>

<exceptionless apiKey="YOUR_API_KEY" />
```

### 3. Check the Exceptionless module

NuGet usually registers this module in web.config for you. It starts the client when your app starts.

```xml
<system.webServer>
  <modules>
    <remove name="ExceptionlessModule" />
    <add name="ExceptionlessModule" type="Exceptionless.Mvc.ExceptionlessModule, Exceptionless.Mvc" />
  </modules>
</system.webServer>
```

### 4. Send a test error

Run this once from a controller action, for example a temporary test endpoint.

```csharp
new Exception("Hello from Exceptionless setup").ToExceptionless().Submit();
```

```csharp
    }
```
